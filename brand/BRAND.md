# 三浦A邸 デザインの約束

近況ボード（`build.py`）とガイド（`guide_build.py`）で実際に使っている見た目を、そのまま全媒体の基準にする。
値の正は `brand/tokens.css`。ここは使い方の約束。

## 1. 三つの柱

1. **白地・墨・海の青**：地は白、文字は墨（#14202B）、主役は海の青（#0A5A8C）
2. **マグロの赤は薬味**：#B8243A は「注意」「号」「強調1か所」だけ。面積は全体の5%以下
3. **明朝で名乗り、ゴシックで伝える**：見出し・屋号は明朝、説明は角ゴ

## 2. 色

| 役 | 名 | HEX | 使いどころ |
|---|---|---|---|
| 地 | 白 | #FFFFFF | 背景 |
| 墨 | ink | #14202B | 本文・罫線 |
| 補助墨 | ink2 / mute | #3E4C58 / #5A6A77 | 注記・日付 |
| 海 | sea | #0A5A8C | 見出しのアクセント・リンク・ボタン・地図の主線 |
| 海の淡 | sea-tint | #E6F0F6 | 囲み・カード地 |
| マグロ | tuna | #B8243A | 警告・避難・「第◯号」・強調1点 |
| マグロの淡 | tuna-tint | #FBEAEC | 警告の囲み |
| 罫・淡灰 | hair / tint | #D9E1E8 / #F2F6F9 | 区切り・面 |

- 文字と地は必ずコントラスト4.5以上。海の青×白は約7:1、マグロ×白は約6:1
- ハザードの「危険」を色だけで伝えない（行政ハザードマップの凡例色とも混ぜない。凡例は行政のものをそのまま、A邸の色は枠・見出し側に使う）

## 3. 書体

| 用途 | 書体 | 代替 |
|---|---|---|
| 屋号・見出し | Shippori Mincho 700–800、字間 .08–.2em | ヒラギノ明朝／游明朝 |
| 本文・案内 | Zen Kaku Gothic New 400–700 | ヒラギノ角ゴ／游ゴシック |
| 欧文小ラベル | 上記ゴシック、字間 .3em、小さく | |

- 本文はスマホで15px以上、行間1.75。ハザードマップ・避難案内は**さらに大きく**（17px以上）
- 印刷は同じ書体（Google Fonts は商用可）。本文8pt以下にしない

## 4. かたち・型

- 角は丸めない。見出しの下に太罫（2px／印刷は0.75pt）
- 「面」見出し：`明朝の大見出し ＋ 小さな英字ラベル ＋ 右に件数や補足`
- 号数の札：マグロ赤の枠で「第◯号」
- 写真は撮影者・出典を欠かさない。事故・事件の報道写真は使わない（場所の写真にする）
- 余白は広く、1画面（1面）に主張は1つ

## 5. 媒体ごとの適用

| 媒体 | 地 | 要点 | 状態 |
|---|---|---|---|
| A邸サイト | 白 | tokens.css をそのまま読む。ヘッダーに屋号（明朝）＋海の青の細い帯 | 元サイトはこのリポジトリ外。**tokens を貼って確認** |
| 近況ボード／ガイド | 白 | 実装済み。基準 | ✅ |
| A邸ハザードマップ | 白 | 避難は「3つのきっかけ」「5ステップ」を海の青の番号で。危険・警告のみマグロ赤。文字大きめ | 公開から外し、合言葉つきページ（`share_lock.py`）。色・書体を tokens に揃える |
| LINEオープンチャット | 正方形アイコン、白地 | アイコン＝「三浦A邸」を明朝で縦組み＋海の青の波1本。小さくても読める。ルーム説明文は2行ルール（事実1行＋話し方1行） | 要制作 |
| チラシ（A4・名刺・カード） | 白＋余白 | 表：屋号・一言・QR（URLはGitHub Pages／ガイド）。海の青ベタ面は裏・帯に限る。QRは墨1色 | 要制作 |

## 6. 印刷（目安）

CMYKは機械的な換算の目安。**必ず色校正を取る**。
- 海 #0A5A8C ≒ C95 M60 Y20 K10 前後
- マグロ #B8243A ≒ M95 Y75 K15 前後
- 墨 #14202B ≒ C80 M65 Y50 K85 前後（K単色にしてもよい）
- 裁ち落とし3mm、文字は端から5mm以上内側

## 7. 次にやること（提案）

1. ハザードマップの配色・書体を tokens に揃える（`hazard-share.src.html`）
2. LINEアイコンとチラシ表を HTML で組み、PDF／PNGに書き出す
3. A邸サイト本体のURL／ソースを共有してもらい、tokens を当てる
